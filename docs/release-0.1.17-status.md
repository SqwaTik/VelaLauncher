# Локальное обновление 0.1.17

24 сентября 2026 установлен лаунчер 0.1.17 с клиентом 0.1.9. NSIS `/S` завершился с кодом 0. Версия подтверждена свойством установленного EXE; SHA-256 установленного `resources/vela-client.jar` совпадает с `build/vela-client.jar`: `1c69833b6dc2e2b5952cd64d25c34c4c5deadec31f6397d8b5751bfe589e9ca`.

Полная предыдущая установка сохранена в `build/installed-full-before-0.1.17`; старый установщик 0.1.16 остаётся в `dist`. Игровые профили и аккаунты вручную не менялись. Управляемый игровой JAR обновляется лаунчером при следующем старте игры.

## Состав

- Gamma с адаптацией к местному освещению, Macros и Interval Commands с общим редактором. По умолчанию выключены. Макрос срабатывает на нажатие; интервальные записи чередуются с общим ограничением отправки. Во время GUI и потери фокуса автоматическая отправка блокируется.
- AutoClicker сохраняет минимум одно действие; по умолчанию выбран Attack.
- Анимированное раскрытие пользовательского цвета Block Overlay и окна назначения клавиши. В переходах после входа сначала рисуется родительский экран, устраняя обнаруженный пустой кадр.
- Кэш РП может использовать архив из другого ID пакета с тем же серверным SHA-1. Штатный HttpUtil повторно проверяет содержимое. Архив уже сжат; дополнительной распаковки или постоянного удержания пакета другого сервера нет.
- Включены ранее подготовленные Auto TPAccept, Aspect Ratio, Block Overlay и кэш подготовленных надписей игроков.
- FG удалена из активного клиента и лаунчера по запросу пользователя. Исходники сохранены отдельно в `work/retired-fg-20260923`.

## Проверка и ограничения

Gradle build успешен; 197 тестов без ошибок. 13 проверок runtime лаунчера, electron-vite и electron-builder успешны. Исправлена обнаруженная запуском ошибка Mixin кэша: вместо перенаправления вызова внутри lambda используется HEAD самого `DownloadQueue.runDownload`. Повторный запуск прошёл; журнал подтверждает `Using graphics backend Vulkan`. Авторизация Realms dev-профиля возвращает ожидаемый 401. В Windows имеются предупреждения OSHI о счётчиках Perflib; системные настройки не менялись.

Свежий adversarial review обнаружил и помог исправить голодание интервальных команд; тест покрывает две конкурирующие записи. Тест кэша проверяет отбрасывание повреждённого файла штатным HttpUtil, загрузку корректного содержимого и повторный cache hit без соединения.

Визуальная проверка новых редакторов, реальный вход Microsoft и серверный Auto TPAccept пока не завершены. На момент проверки пользователь уже играл на сервере; управление не перехватывалось. Устранение просадок FPS в толпе не подтверждено новым сравнительным замером.

## Следующая работа: постепенное применение РП

Пользователь описал мод, в котором элементы ресурс-пака появлялись постепенно; название неизвестно. Это отдельная задача от дискового кэша. Она пока не реализована. В MC26.2 `SimpleReloadInstance` разделяет фоновые preparation-задачи и main-thread apply-задачи с общим барьером и последовательными зависимостями слушателей. Нужно измерить длительности apply моделей/атласов/загрузки GPU и проверить возможность дробления без показа несогласованных ресурсов. Нельзя обещать полное отсутствие задержек или безопасно разнести все apply-этапы произвольно. Сохранить согласие пользователя, проверку хэша и достоверное завершение загрузки.

Принцип адаптивной Gamma изучен по [FullBright](https://github.com/RealDevJG/FullBright); реализация собственная. Поведение кэша и барьеров проверялось по исходникам установленного Minecraft 26.2 (`HttpUtil`, `DownloadQueue`, `SimpleReloadInstance`).
