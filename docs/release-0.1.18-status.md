# Обновление редактора команд 0.1.18

Клиент 0.1.10: Macros и Interval Commands используют явный режим создания и редактирования. После успешного добавления форма очищается для следующей записи. Выбор записи в списке открывает редактирование, кнопка меняется с «Добавить» на «Сохранить». Создание нескольких записей подряд и изменение выбранной покрыты `CommandDraftTest`.

«Создать» показывает плюс при наведении через общий механизм анимаций. Идентичность остальных кнопок больше не зависит от меняющейся подписи. Добавлены переходы формы, плавное выделение полей и видимая дорожка прокрутки с захватом ползунка. Удаление выполняется одним нажатием. Подпись состояния — «Макрос включён» или «Таймер включён».

Вход в аккаунт возвращён внутрь боковой панели. При закрытии экран входа рисуется поверх уже восстановленного списка, включая последний кадр перехода. Подлинная авторизация автоматически не проверялась.

Gradle build: 198 тестов без ошибок. Runtime лаунчера: 13 проверок. Резервная копия установленной 0.1.17 находится в `build/installed-full-before-0.1.18`.

Правило запуска для дальнейших пользовательских тестов: устанавливать обновлённую сборку и запускать Minecraft через установленный Vela Launcher. Прямой `runClient` не использовать для таких тестов.
