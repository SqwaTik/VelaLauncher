# Обновление 0.1.19 / клиент 0.1.11

Редакторы Macros и Interval Commands: фон затемнения приведён к настройкам, крестик использует общий hover-контрол, убрана однотонная плашка и задержка переключения записей. Общие действия «Создать» и «Добавить» показывают плюс слева со сдвигом текста. Исправлена автопрокрутка после добавления: цель ограничивается до интерполяции, исключён `Float.MAX_VALUE`.

Фон имени друга над игроком использует цвет `0x506FD92B` из таба. Текст связывается с реальным профилем игрока при извлечении состояния; подсветка не определяется по серверному префиксу. Реестр ограничен 512 ссылками и синхронизирован между потоками. Второй текстовый проход без фона сохраняется.

Click Pearl: отдельная `KeySetting` с клавиатурой/мышью и `None`; один бросок на нажатие; жемчуг только из слотов 0–8. Выбор слота, `gameMode.useItem`, возврат в `finally` и обычная синхронизация предмета Minecraft. В GUI, неактивном окне, во время использования предмета и разрушения блока бросок блокируется. Серверный кулдаун не отменяется.

Crystal Optimizer: только локальные задержки ручного ввода — rightClickDelay при удержании кристалла и missTime при наведении на EndCrystal. Не создаёт и не удаляет сущности, не подменяет серверное подтверждение. Нулевой пинг и нулевая серверная задержка не реализованы и не обещаются. Обе функции по умолчанию выключены.

202 теста клиента прошли; 13 runtime-проверок лаунчера прошли. Источники сигнатур: установленный MC26.2 sources.jar и проверка байткода. Fresh review выявил ошибку автопрокрутки, исправленную до упаковки. Реальный бросок жемчуга, работа кристаллов на сервере и визуальная проверка зелёного фона требуют пользовательского теста.

Предыдущая установка сохранена полностью в `build/installed-full-before-0.1.19`. Пользовательские тесты запускать только через установленный лаунчер. Не менять авторизацию и не заходить на сервер от имени пользователя.

Открытые предыдущие задачи: постепенное применение РП и подтверждение стабильности FPS в толпе. Они не закрыты этим обновлением.
