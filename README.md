# Vela Launcher

Настольный лаунчер для клиента Vela на Electron, Vue 3 и TypeScript. Он ставит Minecraft, загрузчик, Java и сам Vela, а для каждого экземпляра можно выбрать свою версию игры и загрузчик.

## Версии

| Minecraft | Fabric | NeoForge | Java |
|---|---|---|---|
| 26.3 | да | да | 25 |
| 26.2 | да | да | 25 |
| 1.21.11 | да | да | 21 |
| 1.21.5 | да | да | 21 |
| 1.21.4 | да | да | 21 |

Версия и загрузчик выбираются при создании экземпляра и потом не меняются. Для другой версии создай новый экземпляр, их может быть до четырёх. В каждом экземпляре свои моды, настройки и миры.

Список поддерживаемых версий лежит в `src/shared/targets.ts`. Сборки Vela для них лежат в `build/clients/vela-client-<версия>-<загрузчик>.jar` и попадают в установщик.

## Возможности

- Установка Minecraft, загрузчика, Java и Vela с подробным прогрессом. Загрузчик — Fabric Loader вместе с Fabric API или NeoForge, Java — 25 или 21, смотря что нужно версии.
- Пауза, продолжение и отмена загрузки.
- Запуск игры с автоматическим выбором Java и настраиваемой памятью.
- Каталог Modrinth: поиск, фильтры, галереи и Markdown-описания. Показываются только моды под версию и загрузчик выбранного экземпляра.
- Проверка совместимости, зависимостей и состояния установленных модов.
- Групповое включение, отключение и удаление модов с подтверждением.
- Импорт и экспорт сборок `.mrpack`. Версия и загрузчик берутся из самой сборки.
- Аккаунты: автономные профили, Ely.by и LittleSkin через authlib-injector. Microsoft-аккаунты добавляются во встроенном Vela Account Manager. Авторизацию, шифрованное хранение и смену сессии обеспечивает In-Game Account Switcher 9.0.7.
- 3D-просмотр и редактор скина: рисование прямо по модели, слои, Classic и Slim, палитра и HEX.
- Свои фоны: изображения, GIF и видео.
- Скриншоты Minecraft на главной странице.
- Discord Rich Presence, стартовое обучение и диалог восстановления после сбоя.
- Интерфейс на русском, английском и испанском.

## Как Vela попадает в игру

- **Fabric.** Vela лежит в `.vela-runtime/vela-client.jar` и подключается аргументом `-Dfabric.addMods`. В папке `mods` его нет.
- **NeoForge.** Vela лежит в `mods/vela-client-<версия>-managed.jar`. В списке модов лаунчера этот файл скрыт и обновляется сам.
- Если в папке экземпляра остались чужие копии Vela или встроенных в него модов (IAS, Bobby, Mod Menu), лаунчер переносит их в `mod-backups`.

## Разработка

Требования: Node.js 20+, npm, Windows 10 или 11.

```bash
npm install
npm run dev
```

Проверки и сборка:

```bash
npm run typecheck
npx tsc --noEmit -p tsconfig.node.json --composite false
node scripts/verify-runtime.mjs
npm run build
npm run dist
```

- `verify-runtime` проверяет установку Vela для каждой версии, переключение Fabric и NeoForge и запуск процессов. Minecraft при этом не запускается.
- `npm run build` собирает приложение в `out/`.
- `npm run dist` дополнительно собирает установщик для Windows в `dist/`.

### Обновить сборки Vela

Сборки делаются в репозитории [VelaClient](https://github.com/SqwaTik/VelaClient), ветка `port/multiversion`:

```bash
cd versions
./gradlew assemble
```

Каждый `versions/<версия>/build/libs/vela-client-*.jar` копируется в `build/clients/vela-client-<версия>-<загрузчик>.jar`. Сборка для 26.2 на Fabric берётся из корня: `./gradlew build`.

## Структура

```text
src/main/          Electron, IPC, установка, Java, аккаунты и Modrinth
src/preload/       безопасный мост между main и renderer
src/renderer/      интерфейс на Vue: страницы, компоненты и хранилища Pinia
src/shared/        общие типы, версии (targets.ts) и каналы IPC
build/clients/     сборки Vela для каждой версии и загрузчика
```

Игровые файлы и настройки хранятся в пользовательском каталоге `.vela` и в репозиторий не входят.
